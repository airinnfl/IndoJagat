# Indo Jagat

Website demonstrasi multi-page berbasis Astro untuk perusahaan alat berat fiktif.

```bash
npm install
npm run dev
npm run check
npm run build
```

Semua produk, statistik, alamat, kontak, testimoni, dan artikel merupakan data placeholder. Ganti logo demo, foto remote, canonical site, dan seluruh data perusahaan sebelum produksi.
